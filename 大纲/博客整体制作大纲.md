## 四、视觉风格规范（Design System · 荧光淡紫粒子未来科技感）

### 4.1 色彩体系（建议值，可微调）

| 角色 | 色值建议 | 用途 |
|---|---|---|
| 背景主色（深空黑紫） | `#0A0616` / `#120B26` | 页面底色，深色才有荧光效果 |
| 背景渐变 | `#0A0616 → #1A1033 → #0D0A1F` | 首屏与各板块底色过渡 |
| 主色 · 荧光淡紫 | `#A78BFA` / `#C084FC` | 标题、强调、发光主体 |
| 亮紫（高光） | `#E9D5FF` / `#D8B4FE` | 文字高光、粒子颜色 |
| 霓虹紫（描边/发光） | `#8B5CF6` / `#B57EFF` | 边框、光晕、按钮 hover |
| 辅助色 · 冷蓝 | `#60A5FA`（点缀） | 数据图表、次级标签（呼应作品集蓝色基因） |
| 文字主色 | `#EDE9FE`（淡紫白） | 正文 |
| 文字次级 | `#A5A3C4` / `#8B89A6` | 注释、说明 |
| 警示/强调橙 | `#F0ABFC` 可选 | 极少量强调（获奖、荣誉） |

### 4.2 字体规范
- 英文/数字标题：`Orbitron`、`Rajdhani`（未来科技感、几何字形）——适用于姓名、大标题、数据
- 中文标题：`思源黑体 Heavy/Medium` 或 `苹方`（保持科技感的同时保证中文可读）
- 正文：`思源黑体 Regular` / `PingFang SC`
- 等宽数字用于数据展示（论文数、专利数、年份）

### 4.3 粒子系统与动效规范（核心视觉）
- **粒子背景（Canvas）**：全屏 Canvas 生成 80-150 个淡紫色光点，颜色在 `#A78BFA / #C084FC / #E9D5FF` 之间随机；缓慢上浮/漂移（呼吸感），带微弱光晕（shadowBlur）；鼠标经过时粒子轻微聚拢/散开互动；移动端降低粒子数保证流畅
- **霓虹发光**：标题与按钮使用 `text-shadow` / `box-shadow` 紫色辉光；卡片边框发光（hover 时加强）
- **玻璃拟态卡片**：`background: rgba(168,85,247,0.06~0.10)` + `backdrop-filter: blur(12px)` + 1px 淡紫描边
- **装饰元素**：淡紫扫描线（首屏）、背景网格线（极淡）、数据光点连线
- **动效**：首屏文字渐入/打字机效果、板块进入视口淡入上移（IntersectionObserver）、数据动态计数、导航吸顶发光
- **约束**：动效不喧宾夺主，正文始终清晰可读；尊重 prefers-reduced-motion

## 六、技术实现方案

- **形态**：单页 HTML（长滚动 + 锚点导航），或板块分页（推荐单页，沉浸感更强）
- **技术栈**：纯 HTML5 + CSS3 + 原生 JavaScript；粒子背景用 Canvas 2D（如需更强 3D 光效可选 Three.js，但注意体积与移动端性能）
- **动效库**：原生 IntersectionObserver + CSS transition 即可；不依赖重框架
- **响应式**：桌面（粒子 100-150）/ 平板 / 手机（粒子 40-60），网格与卡片自适应换行
- **字体加载**：Google Fonts（Orbitron/Rajdhani）或本地字体；中文用系统字体栈
- **性能**：图片压缩（作品集截图建议 WebP）、粒子数动态调节、`prefers-reduced-motion` 兼容
- **部署**：静态文件直接部署（GitHub Pages / 服务器 / 内网均可）
